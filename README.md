# DEX

**Data EXploration made simple.**

## Installation

Download the project as a ZIP from the repository page, or clone it:

```bash
git clone <repository-url>
cd dex
```

Replace `<repository-url>` with the URL of your repo, and adjust the folder name if it differs.

## Usage

Run the script:

```bash
python dex.py
```

If it doesn't run correctly, try:

```bash
python3 dex.py
```

You'll be prompted with:

```
Enter the path to the CSV file:
```

Enter the path to your CSV file and DEX will take it from there.
